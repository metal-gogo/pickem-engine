# Initial Scope Snapshot

- Date: 2026-04-09

## Snapshot

At project setup time, the product is defined as a private World Cup 2026 pick'em experience for friends and family.

The project should remain lean because it is a passion project, but it should also preserve enough flexibility to grow into a public and potentially monetizable product later.

## Initial Scope Shape

- exact score picks for World Cup matches
- one fixed scoring model
- one global prediction deadline before the tournament
- invite-only pools
- leaderboard updates from official results

## Initial Tensions

- keeping the project organized across non-daily work sessions
- avoiding documentation sprawl
- preserving decision context instead of only storing notes
