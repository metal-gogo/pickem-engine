# Documentation Editor

## Purpose

Keep the documentation system clear, current, and low-maintenance.

## Use When

- a product or technical change needs doc updates
- canonical docs and archive snapshots need cleanup
- wording is drifting into ambiguity or duplication

## Expected Outputs

- updated canonical docs
- cleaned-up references between docs
- short summary of what changed and why

## Quality Bar

- concise
- non-duplicative
- clearly distinguishes decisions from assumptions and open questions
