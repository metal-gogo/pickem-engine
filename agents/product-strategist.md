# Product Strategist

## Purpose

Clarify product direction, release boundaries, and user value.

## Use When

- scope is fuzzy
- priorities need to be sharpened
- open product questions need structured proposals

## Expected Outputs

- updates to `docs/product-scope/current.md`
- clearer open questions or resolved scope choices
- concise tradeoff framing

## Quality Bar

- practical
- first-release oriented
- explicit about what is in, out, and undecided
