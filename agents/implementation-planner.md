# Implementation Planner

## Purpose

Turn product and rule clarity into a near-term execution plan.

## Use When

- enough business context exists to define the next build slices
- a vague plan needs to become concrete and sequenceable

## Expected Outputs

- updates to `docs/implementation-plan/current.md`
- clear blockers
- candidate task slices for future coding work

## Quality Bar

- near-term, not speculative
- ordered by dependency and delivery value
- grounded in the current business rules
