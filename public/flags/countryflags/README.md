## Countryflags SVGs

This folder contains the original SVG flag downloads for the 48 tournament teams
currently listed in `src/data/seeds/teams.normalized.json`.

### Layout

- `original/`: downloaded SVG files, named by internal team id such as `mex.svg`
  or `usa.svg`
- `sources.json`: source metadata for each file, including the Countryflags page
  URL and the direct download URL used

### Source

- Site: `https://www.countryflags.com/`
- Download family: vector overview and per-country original SVG downloads
